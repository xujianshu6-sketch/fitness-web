> 🔗 **立即体验**：https://xujianshu6-sketch.github.io/fitness-web/

## ✨ 它为你做什么

- **科学训练记录** —— 记录每次训练的组数、重量、次数，你的每一次进步都有迹可循
- **云端同步，永不丢失** —— 数据实时同步到云端，换手机、换设备，记录依然在
- **打卡热力图** —— 坚持的每一天都看得见，激励自己不停歇
- **能力雷达图** —— 基于训练容量，可视化你的成长曲线
- **2D 肌肉图谱** —— 直观了解每次训练练到了哪些肌群
- **核心动作库** —— 分类清晰、可搜索的训练动作指南
- **训练计划** —— 制定目标，按计划推进
- **健身知识库** —— 训练干货随时查阅

## 🎯 适合谁

- 刚开始健身、想要系统记录训练的朋友
- 想摆脱纸笔和备忘录、用手机管理训练的人
- 任何想看到自己坚持成果的健身爱好者

## 🛠️ 技术背景

- 基于 **uni-app（Vue 3）** 跨端开发，一套代码同时支持 **手机 App** 与 **网页版**
- 后端采用 **uniCloud 云开发**，数据云端存储、安全隔离
- 当前状态：网页版已上线，手机 App 版本同步可用

## 🔒 数据安全

- 手机号一键登录，个人数据严格隔离，他人无法访问
- 云端存储，意外清空本地也能恢复

## 📌 使用提示

- 首次使用：手机号 + 验证码一键登录，自动注册
- 登录一次，5 天内无需重复登录
